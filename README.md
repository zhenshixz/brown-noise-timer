# 棕噪音定时器

一个离线 Android 小应用：每天到指定时间播放手机中的完整 MP3，并在停止时间结束播放。支持每天或仅工作日，支持跨午夜时段。无需将音频设成铃声。

## 安装与使用

1. 在手机上安装 `BrownNoiseTimer-v1.0.1.apk`。
2. 打开应用，点击「从手机文件中选择 MP3」，在 `Download` 中选取棕噪音文件。应用只保存文件访问授权，不会复制 741 MB 的音频。
3. 设置开始、停止时间，按需勾选「仅周一至周五播放」，点击「保存并开启定时」。
4. 按系统提示允许「精确闹钟」。若状态显示「等待授权」，点击「允许精确定时」。
5. 在 OPPO 设置中，将「设置 → 应用 → 应用管理 → 棕噪音定时器 → 耗电管理」设为「完全允许后台行为」；再到「设置 → 应用 → 自启动」开启「棕噪音定时器」。
6. 点击「现在试听」确认媒体音量；首次使用可将开始时间暂时设为一分钟后，锁屏验证定时播放。

手机需要保持开机。不要移动或删除已选择的 MP3，否则需重新选择文件。手机重启后应用会恢复下一次定时；重启发生在播放时段内时，不会自动续播当次音频。

## 技术说明

- Android 8.0 及以上；使用系统文件选择器取得持久读取权限。
- 使用 `AlarmManager` 的精确闹钟触发播放；需要系统授予精确定时权限。
- 播放期间运行媒体前台服务，并显示可停止播放的通知。
- 不申请联网权限；音频只从手机本地读取。
