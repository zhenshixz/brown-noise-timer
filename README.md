# 棕噪音定时器

一个离线 Android 小应用：按多条定时规则播放或停止手机中的完整 MP3。每条规则可单独设置开始、停止或完整时段，并指定每周重复的日期范围。无需将音频设成铃声。

## 安装与使用

1. 在手机上安装 `BrownNoiseTimer-v1.2.0.apk`。
2. 打开应用，点击音频旁的「更换」，在 `Download` 中选取棕噪音 MP3。应用只保存文件访问授权，不会复制原音频。
3. 点击「添加规则」，分别选择是否定时开始、是否定时停止，再设置时间和「从周几到周几」。点击「保存规则」后立即生效；每条规则右侧的开关可以单独启停。
4. 若状态显示缺少精确定时权限，点击「允许精确定时」。
5. 在 OPPO 设置中，将「设置 → 应用 → 应用管理 → 棕噪音定时器 → 耗电管理」设为「完全允许后台行为」；再到「设置 → 应用 → 自启动」开启「棕噪音定时器」。
6. 点击「现在试听」确认媒体音量；首次使用可将开始时间暂时设为一分钟后，锁屏验证定时播放。

仅设置开始时，音频会播放到下一条停止规则、手动停止或文件自然结束；仅设置停止时，到点会停止正在播放的音频。已在播放时遇到另一条开始规则不会从头重播。每条规则的星期范围包含首尾，允许跨周，例如周五至周一。完整时段跨午夜时，重复星期按开始播放当天计算。所有规则共用选中的 MP3。

从 1.0.1 或 1.1.0 升级会保留已选音频和原定时，原来的总开关状态会迁移到各条规则。修改或切换规则不会中断正在播放的音频。

手机需要保持开机。不要移动或删除已选择的 MP3，否则需重新选择文件。手机重启后应用会恢复下一次定时；重启发生在播放时段内时，不会自动续播当次音频。

## 技术说明

- Android 8.0 及以上；使用系统文件选择器取得持久读取权限。
- 使用 `AlarmManager` 的精确闹钟触发播放；需要系统授予精确定时权限。
- 系统中只保留下一次开始和下一次停止闹钟，触发后按规则继续安排。
- 播放期间运行媒体前台服务，并显示可停止播放的通知。
- 不申请联网权限；音频只从手机本地读取。
